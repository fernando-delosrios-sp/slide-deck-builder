Data Model Cardinality

Entitlements, Access Profiles, and Composite Roles

Architectural cardinality rules governing source aggregation and role composition

Strict Boundary

Access Profile Rule (1 : N)

An Access Profile maps to strictly one source, aggregating N entitlements within that isolated system.

Cross-System Composite

Role Architecture (N : M)

A Role transcends application boundaries, combining N Access Profiles and standalone entitlements across any number of sources.
